# Boots — «Чудо Обувь»

Учебное настольное приложение для магазина обуви. В каталоге можно посмотреть модели, цены и остатки, а сотрудники магазина могут оформлять и обслуживать заказы.

Приложение написано на C# с использованием WPF, .NET 8, Entity Framework Core 8 и Microsoft SQL Server.

## Возможности

| Роль | Доступные действия |
| --- | --- |
| Гость | Просмотр каталога с фотографиями, ценами и остатками. |
| Авторизованный пользователь | Поиск по названию и описанию, сортировка по итоговой цене, просмотр карточки товара и остатков по размерам. |
| Менеджер | Просмотр заказов и их состава, оформление заказа для клиента, удаление заказа с возвратом остатков. |
| Администратор | Возможности менеджера, изменение даты заказа, удаление отдельных позиций и ручное добавление товаров в каталог. |

Для входа используется логин из таблицы `dbo.Users`. Роль определяется по `RoleId`. В каталоге отображаются ФИО и роль текущего пользователя.

### Каталог и заказы

- Остаток в карточке суммируется по всем размерам. До 5 пар включительно отображается «мало», от 6 — «много». До 3 пар включительно карточка подсвечивается светло-красным.
- Товар получает скидку 25%, если его не заказывали в предыдущем календарном месяце. При наличии скидки исходная цена зачёркивается.
- В заказе хранятся клиент, дата, выбранные размеры, количество пар и зафиксированные цены. Итог считается по сохранённым ценам позиций.
- При подтверждении заказа программа проверяет остатки перед списанием. При удалении заказа или позиции пары возвращаются на склад. Запись заказа и изменение остатков выполняются в одной транзакции.
- Администратор может ввести название, описание, состав и цену нового товара, выбрать производителя, подкатегорию и фотографию, а также задать остатки по размерам.

## Запуск

Понадобятся Windows, .NET 8 SDK и доступ к экземпляру SQL Server с базой `ShopBootsDB`.

1. Если база на другом компьютере, сначала восстановите `ShopBootsDB` из SQL-скрипта со структурой и данными.
2. Укажите параметры подключения к SQL Server в `Boots/Data/AppDbContext.cs`. Для Windows внутри Parallels используйте адрес сервера, доступный из виртуальной машины.
3. Откройте `Boots.slnx` в Visual Studio и нажмите **F5**. Для запуска из PowerShell в корне репозитория выполните команду ниже.

```powershell
dotnet run --project Boots/Boots.csproj
```

Штатные фотографии находятся в `Boots/res`. Фотографии, загруженные через форму добавления товара, хранятся в `%LOCALAPPDATA%\Boots\Images` у пользователя Windows. При переносе приложения вместе с базой скопируйте эту папку, чтобы фотографии новых товаров были доступны.

## Структура проекта

- `Boots/Data` — подключение к SQL Server, расчёт цены и операции с товарами и заказами.
- `Boots/Models` — модели товаров, пользователей, остатков и заказов.
- `Boots/MainWindow.xaml` — вход по логину и вход гостем.
- `Boots/ProductWindow.xaml` и `Boots/ProductDetailsWindow.xaml` — каталог и карточка товара.
- `Boots/OrdersWindow.xaml` и `Boots/OrderCreateWindow.xaml` — список заказов, состав и оформление.
- `Boots/ProductCreateWindow.xaml` — добавление товара.
